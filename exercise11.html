JavaScript If and Else Statements

JavaScript uses if and else statements to make decisions in a program. They allow the code to do different things depending on whether a condition is true or false. This is useful when a program needs to check information before deciding what to do next.

The if Statement

An if statement runs a block of code only when its condition is true. The condition is placed inside parentheses after the word if. The code that should run is placed inside curly braces. 

if (condition) {
    // code runs if the condition is true
}

For example:

let temperature = 80;

if (temperature > 70) {
    console.log("It is warm outside.");
}

In this example, JavaScript checks whether temperature is greater than 70. Since the value is 80, the condition is true and the message is displayed.

The else Statement

An else statement gives the program another option when the if condition is false. The else statement does not have its own condition. It runs when the condition in the if statement is not true. 

let temperature = 55;

if (temperature > 70) {
    console.log("It is warm outside.");
} else {
    console.log("It is not very warm outside.");
}

Here, the temperature is 55, so the condition is false. The code inside the else section runs and displays the second message.

The else if Statement

An else if statement is used when there are more than two possible conditions. JavaScript checks each condition in order. When it finds a condition that is true, it runs that block of code and skips the remaining conditions. 

let score = 85;

if (score >= 90) {
    console.log("You got an A.");
} else if (score >= 80) {
    console.log("You got a B.");
} else if (score >= 70) {
    console.log("You got a C.");
} else {
    console.log("You need to keep studying.");
}

In this example, the score is 85. The first condition is false because 85 is not at least 90. The second condition is true because 85 is at least 80, so the program displays "You got a B."

Comparison Operators

Conditions often use comparison operators to compare two values. The result of a comparison is either true or false.

  • == checks if two values are equal.
  • === checks if two values are equal in value and type.
  • != checks if two values are not equal.
  • !== checks if two values are not equal in value or type.
  • > checks if the left value is greater than the right value.
  • < checks if the left value is less than the right value.
  • >= checks if the left value is greater than or equal to the right value.
  • <= checks if the left value is less than or equal to the right value.

Using More Than One Condition

JavaScript also allows conditions to be combined. The && operator means both conditions must be true. The || operator means at least one condition must be true. The ! operator changes a true condition to false or a false condition to true. 

let age = 20;
let hasLicense = true;

if (age >= 16 && hasLicense) {
    console.log("You can drive.");
} else {
    console.log("You cannot drive.");
}

In this example, both conditions must be true for the first message to display. If either condition is false, the else section runs.

Why If and Else Statements Are Useful

If and else statements are important because they let a program respond to different situations. They can be used to check a user's age, compare scores, validate information in a form, or decide what message to show. Without conditional statements, a program would not be able to make these kinds of decisions.
